Setup Guides & Deployment Documentation

Instructions for Nginx Proxy Manager (NPM), Kodi, TiviMate, VLC, and Portainer.

NPM

Exposing via Nginx Proxy Manager (NPM) & Public IP

Access your M3U and EPG securely from anywhere on the internet.

With a Public IP and Nginx Proxy Manager (NPM), you can assign a domain (e.g., tv.yourdomain.com) with a free SSL certificate from Let's Encrypt.

Step 1: Port Forwarding

On your home router, forward external ports 80 and 443 to the local IP of your Nginx Proxy Manager host.

Step 2: Add Proxy Host in NPM
  • Domain Names: tv.yourdomain.com
  • Scheme: http
  • Forward Hostname / IP: Local IP of this server or container name (e.g. sweettv-proxy or 192.168.1.xxx)
  • Forward Port: 5000
  • Enable: Websockets Support • Block Common Exploits
Step 3: SSL Certificate
  • Switch to the SSL tab in NPM.
  • Select Request a new SSL Certificate (Let's Encrypt).
  • Check Force SSL and HTTP/2 Support.
Step 4: Update External Domain in Settings

Open the Settings Tab above and set External Domain to https://tv.yourdomain.com. This ensures all generated M3U channel URLs and catchup links use your HTTPS domain!

Kodi

Kodi (PVR IPTV Simple Client)

Full TV guide, logos, categories, and catchup replay in Kodi.

  1. Install PVR IPTV Simple Client in Kodi (Settings → Add-ons → Install from repository → PVR clients → PVR IPTV Simple Client).
  2. Open the add-on configuration → General tab:
    M3U Playlist URL: {{ base_url }}/playlist.m3u
  3. Switch to the EPG tab:
    XMLTV URL: {{ base_url }}/epg.xml.gz
  4. Switch to the Catchup tab:
    • Enable Catchup: Yes
    • Catchup mode: Default (or Append to URL)
    • Query format: {catchup-id}
TV

TiviMate & Android TV Players

Best-in-class IPTV experience on Google TV, FireTV, and Shield.

  1. In TiviMate, go to Settings → Playlists → Add Playlist.
  2. Select M3U Playlist and enter the URL: {{ base_url }}/playlist.m3u.
  3. In the EPG section, enter the guide URL: {{ base_url }}/epg.xml.
  4. In Playlist options, ensure Catchup is set to Auto or Type: Xtream Codes / Flussonic / VOD.
Docker

Docker Compose & Portainer Stack

One-click stack deployment with persistent data volume.

In Portainer, click Stacks → Add stack → Web editor and paste:

version: '3.8'

services:
  sweettv-proxy:
    image: sweettv-proxy:latest
    build: .
    container_name: sweettv-proxy
    restart: unless-stopped
    ports:
      - "5000:5000"
    environment:
      - HOST=0.0.0.0
      - PORT=5000
      - EXTERNAL_URL=https://tv.yourdomain.com  # Optional: your NPM public domain
      - SWEETTV_COUNTRY_CODE=cs                # cs, sk, hu, pl, uk, ro
      - DEFAULT_QUALITY=auto                   # auto, best, 1080p, 720p
      - DIRECT_REDIRECT=true
    volumes:
      - sweettv_data:/app/data

volumes:
  sweettv_data:
    name: sweettv_data
